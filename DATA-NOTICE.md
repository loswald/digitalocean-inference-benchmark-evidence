# Data notice

The `results/` tree contains sanitized benchmark identities, HTTP status
classes, task scores, timing observations, server-reported token usage,
estimated cost, coverage decisions, and derived summaries produced while
testing DigitalOcean Serverless Inference. It does not publish prompts, model
response text, raw response bodies, raw headers, or credentials.

The MIT License applies to the original benchmark code and authored report
text. It does not grant additional rights in DigitalOcean trademarks,
third-party model weights, or provider/model-generated responses. Those
materials remain subject to their applicable terms. The measurement records
are provided as research evidence and should not be treated as a training-data
license.

No customer data was used. Test prompts were programmatic or synthetic.
